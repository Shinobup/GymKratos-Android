# 🏋️‍♂️ Gym Kratos - Sistema de Gestión Móvil

Aplicación nativa para Android desarrollada para la gestión administrativa y financiera de un gimnasio real. El sistema permite el control de membresías, automatización de cobros y análisis de ingresos en tiempo real.

## 🚀 Características Principales
* **Arquitectura Serverless:** Base de datos gestionada en la nube mediante Google Sheets y Google Apps Script (API REST customizada).
* **Gestión de Clientes (CRUD):** Registro de nuevos ingresos, visualización de estado de membresías y módulo de renovación.
* **Lógica Financiera Automatizada:** Menús dinámicos en cascada que asocian disciplinas con precios fijos, y un módulo de "Plan Especial" para montos personalizados.
* **Dashboard de Finanzas:** Cálculo en tiempo real de los ingresos totales del mes y desglose automático de ganancias por disciplina (Pesas vs. Artes Marciales).
* **Módulo de Cobranza Inteligente:** Integración con la API de WhatsApp para el envío automatizado de recordatorios de pago a clientes con membresías vencidas (cálculo de fechas automático).
* **Validación de Datos:** Filtros estrictos de formato para números de teléfono (+569) y campos de entrada para mantener la integridad de la base de datos.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java (Android SDK)
* **Entorno:** Android Studio
* **Peticiones HTTP:** Librería Volley
* **Base de Datos / Backend:** Google Sheets + Google Apps Script (JavaScript)
* **Formatos de datos:** JSON para comunicación cliente-servidor.
